# 🐍 Snake Game

A classic Snake Game built with Python and Turtle.

## Features

- Control the snake with arrow keys.
- Eat food to grow.
- Score increases when food is collected.
- Game ends when the snake hits the wall or its tail.

## Technologies

- Python 3
- Turtle graphics
- Object-oriented programming


## Controls

| Key | Action |
|---|---|
| Up Arrow | Move up |
| Down Arrow | Move down |
| Left Arrow | Move left |
| Right Arrow | Move right |

## Project Files

- `main.py` — Runs the game.
- `snake.py` — Controls snake movement.
- `food.py` — Creates and positions food.
- `scoreboard.py` — Displays the score and game-over message.
